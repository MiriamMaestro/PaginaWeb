# Psicología con M — web editable

Esta carpeta contiene una copia editable de las cuatro páginas públicas del sitio:

- `index.html`
- `terapia-de-pareja/index.html`
- `terapia-perinatal/index.html`
- `contacto/index.html`

## Vista local

Desde esta carpeta ejecuta:

```bash
python3 -m http.server 8000
```

Después abre `http://localhost:8000`.

## Páginas

- Inicio: `/`
- Terapia de pareja: `/terapia-de-pareja/`
- Terapia perinatal: `/terapia-perinatal/`
- Contacto: `/contacto/`

El repositorio puede publicarse como privado desde Visual Studio Code mediante **Publish to GitHub** y compartirse añadiendo al editor como colaborador.

Los estilos de las páginas de terapia están incluidos en sus archivos HTML. Parte de las imágenes y recursos de la portada original se cargan desde la web publicada, por lo que se necesita conexión a Internet para verlos correctamente.
